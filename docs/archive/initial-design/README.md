# Initial design notes (superseded)

These documents are the first design sketch, written before the solution was built. Several details
differ from what was built: thresholds in dollars, Teams adaptive cards, an "Order History" screen,
a 72-hour approval timeout, and other role and column names.

The built solution is described in [docs/architecture.md](../../architecture.md), with requirement
notes in [docs/requirements-checklist.md](../../requirements-checklist.md). These files are kept
for history only.
