# Power Automate: Supplier Order Email

## Flow Name: Send Supplier Order Email

**Type:** Automated Cloud Flow (child flow, or continuation of Approval Flow)  
**Trigger:** When a Supply Order status changes to Approved (status = 4)

---

## Flow Definition

### Trigger: When Order is Approved

**Connector:** Microsoft Dataverse  
**Action:** When a row is added, modified or deleted  
**Table:** Supply Orders  
**Change type:** Modified  
**Filter rows:** `cr_orderstatus eq 4 and cr_supplieremailsent eq false`

---

### Step 1: Get Order with Line Items

**Action:** Get a row by ID (Dataverse)  
**Table:** Supply Orders  
**Row ID:** `triggerBody()?['cr_supplyorderid']`  
**Expand Query:** `cr_requestedby,cr_supplier`

---

### Step 2: List Line Items with Item Details

**Action:** List rows (Dataverse)  
**Table:** Order Line Items  
**Filter rows:** `_cr_order_value eq '@{triggerBody()?['cr_supplyorderid']}'`  
**Expand Query:** `cr_pantryitem($select=cr_name,cr_unit,cr_unitprice,cr_category)`

---

### Step 3: Determine Supplier

**Action:** Condition  
**Check:** Does the order have a designated supplier?

**If Yes:** Use the order's supplier  
**If No:** Group items by preferred supplier and send separate emails

---

### Step 4: Build Line Items HTML Table

**Action:** Create HTML table  
**From:** Line items array  
**Columns:**
| Header | Value |
|--------|-------|
| Item | `items('Apply_to_each')?['cr_pantryitem/cr_name']` |
| Category | `items('Apply_to_each')?['cr_pantryitem/cr_category']` |
| Quantity | `items('Apply_to_each')?['cr_quantity']` |
| Unit | Unit label lookup |
| Unit Price | `$items('Apply_to_each')?['cr_unitprice']` |
| Line Total | `$items('Apply_to_each')?['cr_linetotal']` |

---

---

### Step 6: Send Email to Supplier

**Action:** Send an email (V2) (Office 365 Outlook)  
**To:** Supplier's email from Dataverse  
**Subject:** `Supply Order @{outputs('Get_Order')?['body/cr_ordernumber']} - [Company Name]`  
**Body:** Composed HTML from Step 5  
**Importance:** Normal

---

### Step 7: Update Order Record

**Action:** Update a row (Dataverse)  
**Table:** Supply Orders  
**Row ID:** Order ID  
**Values:**
- Supplier Email Sent: `true`
- Order Status: `6` (Sent to Supplier)
- Expected Delivery: `addDays(utcNow(), supplier's lead time)`

---

### Step 8: Notify Requester

**Action:** Post message in a chat or channel (Microsoft Teams)  
**Post as:** Flow bot  
**Post in:** Chat with requester  
**Message:**
```
📧 Your pantry order {Order Number} has been sent to {Supplier Name}.
Expected delivery: {Expected Delivery Date}

Order Total: ${Total Amount}
Items: {Item count} items
```

---

## Flow Diagram

```
[Trigger: Order Approved & Email Not Sent]
         │
         ▼
[Get Order Details + Supplier]
         │
         ▼
[List Line Items]
         │
         ▼
[Build HTML Table of Items]
         │
         ▼
[Compose Formatted Email]
         │
         ▼
[Send Email to Supplier]
         │
         ▼
[Update Order: Email Sent = true]
         │
         ▼
[Notify Requester via Teams]
```

---

## Auto-Approved Orders (No Approval Needed)

For orders that don't require approval (under budget and quantity thresholds), the supplier email is triggered directly when the order status is set to Approved (status = 4) by Power Apps during submission. The same flow handles both paths since it triggers on any order reaching Approved status with `supplieremailsent = false`.
